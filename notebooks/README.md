# Notebooks

Optional Colab notebooks for students who want to code. They use the same `engine/` package as the apps.

| Notebook | Session | What it does |
|---|---|---|
| `s3_robo_lab.ipynb` | 3 | Runs the reference robo on the student data kit: model portfolio → backtest with costs, fees and drift-band rebalancing → the "Excel way" (daily, free) for comparison → goal-based vs profile-based simulation. Shows what a real engine adds to a spreadsheet SUMPRODUCT. |

Open in Colab: upload the notebook, then run the first cell, which clones this repo and installs nothing else (pandas and numpy are already there).
